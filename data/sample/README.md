# Synthetic Sample Data

`sample_tech_spec_ru.txt` and `sample_tech_spec_ru.pdf` are synthetic technical specifications with the same high-level structure as a procurement PDF:

- customer and organizer fields
- fake BIN value
- procurement number and lot
- service scope
- delivery/service period
- payment terms
- technical requirements
- supplier risk clauses

No real company, person, phone number, email, or procurement record is included.
