# Data

This repository does not include real procurement documents, client files, usage logs, or production datasets.

The original local PDFs were removed from the public portfolio version because they contained real organization names, contact details, and procurement metadata. Use the synthetic sample PDF in `data/sample/` for demos and tests.

To regenerate the sample PDF after installing Python dependencies:

```bash
python scripts/generate_sample_pdf.py
```

The generated file is safe to share and is intended only to demonstrate the document-ingestion workflow.
